剧本 YAML Schema

四级层级：Script → Chapter → Scene → Beat。 全文共 14 个模型，每个 Beat 附带分镜建议（镜头/声音/情绪）。

Script — 完整剧本
字段类型必填说明
version str 必填 Schema 版本号，当前为 "1.0"
metadata ScriptMetadata 必填 元信息：标题、原作者、改编者、一句话梗概、类型
characters list[Character] 可选 角色列表
chapters list[Chapter] 可选 章节列表（推荐）。如不提供则回退到 scenes[] 扁平模式
scenes list[Scene] 可选 向后兼容：旧 API 扁平场景列表
设计原因：Script 同时支持 chapters[] 和 scenes[] 两种顶层结构。 新项目推荐使用 chapters[] 四级层级，旧项目 scenes[] 依然可用。 通过 all_scenes() 和 all_beats() 方法统一访问。
ScriptMetadata — 剧本元信息
字段类型必填说明
titlestr 必填 剧本标题
authorstr 必填 原作者
adapted_bystr 可选 改编者
loglinestr 必填 一句话梗概，≤50 字
genrestr 必填 类型： 剧情 喜剧 悬疑 科幻 动作 爱情
page_countint 可选 预估页数
Chapter — 章节
字段类型必填说明
idint 必填 章节序号，从 1 开始
titlestr 必填 章节标题，如 "第一章 初入江湖"
summarystr 可选 章节内容摘要
sceneslist[Scene] 可选 本章场景列表
设计原因：Chapter 对应原小说的自然分章边界，每章包含若干场景。 chapter.id 必须连续递增，硬规则校验会检查这一点。
Scene — 场景
字段类型必填说明
idint 必填 场景序号（章内唯一）
timeline_typestr 可选 时间线类型： present flashback flashforward 默认 present
slugstr 必填 好莱坞格式 Slug，如 "INT. 咖啡馆 - 日" 格式：INT./EXT. 地点 - 日/夜/黄昏/黎明
settingSetting 必填 包含 location（地点）和 time_of_day（时段）
scene_purposestr 可选 场景作用： 推动剧情 揭示角色 建立世界观 制造冲突
characters_in_scenelist[str] 可选 出场角色 ID 列表
beatslist[Beat] 可选 分镜列表（推荐）
actionslist[Action] 可选 向后兼容：旧版动作描写
dialogueslist[Dialogue] 可选 向后兼容：旧版对话块
设计原因：过去 actions[] / dialogues[] 分离导致叙事流断裂。 beats[] 统一了所有叙事单元，按自然顺序排列，每个 Beat 标记其类型。 旧字段保留以确保降级兼容。
Beat — 分镜（最小叙事单元）
字段类型必填说明
idint 必填 分镜序号（场景内唯一，从 1 开始）
typeBeatType 必填 分镜类型： action 动作 — dialogue 对白 — narration 旁白 — transition 转场
descriptionstr 必填 内容描述（动作描写 / 台词 / 旁白文本 / 转场说明）
characterstr 条件必填 关联角色 ID。 action / dialogue 类型必填；narration / transition 可选
shot_suggestionShotSuggestion 可选 镜头与声音建议
设计原因：Beat 是 Hollywood 剧本的标准最小单元。 每个 Beat 对应一个独立的叙事动作——这种粒度让导演/摄影师可直接据此规划实拍方案。 action/dialogue Beat 必须有 character 字段，硬规则校验会强制执行。
ShotSuggestion — 分镜提示
字段类型必填说明
camera_hintstr 可选 镜头建议： 远景 中景 近景 特写 过肩 俯拍 跟拍
sound_hintstr 可选 声音建议： 配乐 音效 环境音 静默 人声
emotionstr 可选 情绪基调： 紧张 温馨 悲伤 激昂 平静 恐惧 浪漫 悬疑 愤怒 幽默
设计原因：ShotSuggestion 是 AI 改编的核心增值点。 LLM 分析叙事内容后自动推断最佳镜头、声音和情绪， 为摄影师/导演提供起点参考，而非替代专业判断。 三个字段均为可选，不强制生成。
Character — 角色
字段类型必填说明
idstr 必填 角色唯一 ID（英文/拼音，如 zhang_san）
namestr 必填 角色名（中文/英文）
age_rangestr 可选 年龄区间，如 "25-35"
descriptionstr 必填 角色描述（外貌/性格/背景）
importance_scorefloat 可选 重要度评分 0-1
